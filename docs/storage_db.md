# Worker 数据库管理

管理后台 `/storage/db` 操作的是 `data/worker.db`，与 Node 和 Python Worker SDK 共用数据库，不包含平台配置所在的 `app.db`。

## 查询

- 左侧选择数据表，可搜索表名。操作栏的表结构按钮显示字段、类型、主键、默认值、生成字段及建表语句。
- WHERE 输入框只填写条件，例如 `status = 'active' AND id > 10`，不需要填写 `WHERE` 关键字。
- 输入字段名前缀时，候选列表显示在输入框正下方。使用 ↑↓ 选择、Enter 插入字段名、Esc 关闭；也可以点击候选项。补全会为字段名添加双引号，支持包含空格或保留字的字段。
- 点击“查询”或按 `Ctrl/Cmd + Enter` 执行；输入过程中不会自动查询。
- 支持 SQLite 条件表达式和子查询，不支持多条语句及 SQL 注释。语法错误会显示在页面，修正后可再次执行。
- 点击列头切换升序、降序。每页可选 20、50、100 行；删除导致当前页越界时自动回到最后一页。

## 新增和编辑

点击操作栏“添加行”或行末“编辑行”打开抽屉，填写后点击“提交”直接保存，无需再次确认。

新增时，“使用默认值”表示不传入该字段，由 SQLite 应用默认值、自增主键或空值；未满足必填约束时会在抽屉中显示错误。编辑只写入实际修改的字段。生成字段只读。

字段支持文本、整数、小数、NULL、二进制类型。空字符串与 NULL 独立处理；整数以字符串传输，避免 JavaScript 丢失 64 位整数精度；二进制内容使用十六进制输入和显示。日期文本保留数据库中的原始格式。

优先通过非空主键（含复合主键）或整数行号主键定位记录；没有可靠主键时使用内部行号，`WITHOUT ROWID` 表使用完整主键。无法取得行标识的表只提供浏览和新增。

查询结果携带原始字段值的版本摘要。编辑和删除会在同一事务中核对当前记录与原始版本；记录被 Worker 修改、删除或被不同内容的新记录替换时，会拒绝过期操作并提示刷新，避免行号复用导致误操作。

## 批量删除

1. 勾选要删除的行，表头复选框仅全选当前页。
2. 点击操作栏“删除”，选中行变灰，此时尚未请求删除接口。
3. 点击“提交”，后端在同一事务中删除全部标记行。任意行删除失败时全部回滚，页面保留标记和错误信息。

行末撤销按钮取消该行标记，操作栏撤销按钮取消所有标记。新增、编辑保存后仍保留其他行的删除标记；操作栏始终显示待删除数量。手动刷新、切换表、重新查询、切换排序或分页，以及站内跳转、前进和后退时，如果存在待删除行，会提示是否放弃标记；取消则保留原状态。删除提交期间不允许站内离开，关闭或刷新浏览器仍使用浏览器原生离开提示。

## 管理接口

接口位于配置的 Admin 前缀下，均使用现有管理员认证和 `{code, msg, data}` 响应结构。数据库操作使用请求上下文，超时为 5 秒。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/db/tables` | 返回用户数据表列表 |
| POST | `/api/db/query` | 接收 `table`、`where`、`page`、`page_size`、`sort_column`、`sort_direction`，返回表结构及分页结果 |
| POST | `/api/db/rows/create` | 接收 `table`、`values`，新增一行 |
| POST | `/api/db/rows/update` | 接收 `table`、`identity`、`version`、`values`，修改一行 |
| POST | `/api/db/rows/delete` | 接收 `table`、`rows`，事务删除多行；`rows` 为 `{identity, version}` 数组 |

`values` 和 `identity` 为字段名到 `{type, value}` 的映射，`type` 为 `text`、`integer`、`real`、`null` 或 `blob`，`value` 为字符串。行标识和版本摘要必须使用查询结果中的 `identity` 与 `version`，不得用筛选条件代替或省略版本。管理接口不改变 Worker SDK 和 magic-api 的现有协议。
